🔧 Installation Instructions

  1. Open Chrome and navigate to chrome://extensions/
  2. Enable "Developer mode" in the top right corner
  3. Click "Load unpacked" and select the chrome-extension folder
  4. The extension should appear in your extensions list
  5. Navigate to any LinkedIn job page to see the extension in action

🧪 Testing

To test the extension:

  1. Install the extension in Chrome
  2. Navigate to a LinkedIn job posting (e.g., linkedin.com/jobs/view/123456789)
  3. Look for the blue "Autofill this job application!" button
  4. Click the extension icon to see the popup interface
  5. Right-click the extension icon and select "Options" to see the settings page
